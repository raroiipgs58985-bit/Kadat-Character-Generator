# Kadat Character Generator

Техническая модернизация генератора Кадата, версия 2.0. Четыре конструктора: персонаж, полк, ксено-раса/зверь и серво-броня. Правила и каталоги перенесены из версии `c04816b` без изменения баланса.

## Запуск

Нужен Node.js 20 или новее. Приложение не требует установки зависимостей для запуска:

```sh
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Другой порт: `npm start -- 8080`.

Приложение полностью статическое: сервер данных, учётная запись, внешние CDN и сборка не нужны. Для статического хостинга достаточно `index.html`, `src/`, `styles/` и `assets/`. Используйте постоянный адрес приложения: localStorage привязан к адресу и профилю браузера.

## Работа с генератором

1. Выберите расу и мир либо ранее сформированный полк; заполните обязательные выборы.
2. Выберите специальность. Каталог учитывает расу и пол.
3. Распределите очки или бросьте 2к10; выполните переносы при необходимости.
4. Приобретите развитие за ОО. Покупки и переносы можно отменять.
5. Проверьте замечания, сформируйте досье и скачайте Excel.

В боковой сводке обновляются профиль характеристик, раны и бюджет опыта. Для полка показаны бюджеты создания и снабжения, для брони — масса компонентов, броня и свободные слоты после манипуляторов. Незаданные источником значения не вычисляются самостоятельно.

Черновики четырёх режимов сохраняются автоматически в этом браузере. **Скачать JSON** сохраняет резервную копию всех черновиков, полков и созданной расы; **Открыть JSON** восстанавливает её. Ошибка чтения или нехватка места показывается в интерфейсе. Перед переносом на другой адрес скачайте JSON.

Excel содержит прежнюю компактную карточку и три подробных листа: числовые данные, навыки/снаряжение, правила/развитие. Это снимок персонажа; редактирование Excel не меняет черновик генератора. Печать досье доступна отдельно.

## Разработка и проверки

```sh
npm ci
npm test
npm run format:check
```

Только инструменты разработки используют npm-зависимости: JSDOM и Prettier, версии закреплены в lockfile. `npm test` проверяет каталоги, 507 эталонов старого движка, расчёты, пользовательские действия в DOM, восстановление данных, HTTP-запуск и XLSX. GitHub Actions запускает те же проверки.

- [Отчёт первого этапа и вопросы правил](docs/MODERNIZATION_REPORT.md)
- [План, составленный после исследования](docs/MODERNIZATION_PLAN.md)

Браузерная проверка адаптивной вёрстки и печати на реальных устройствах остаётся обязательной перед публикацией. В рабочей среде облачный браузер блокировал открытие локальной версии; проверки JSDOM не подтверждают качество раскладки в Chromium, Firefox или Safari.
