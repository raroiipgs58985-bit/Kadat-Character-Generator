## Ritual session

- Демо-пул: **28 разных card identities** (6 Major, 22 Minor), названия из предоставленного источника/сохранённой локализации. Все иллюстрации — три прежних локальных SVG. Повтор SVG между разными картами допустим в этой демонстрации; это не финальная курация.
- Весь набор выбирается без возвращения при единственном подтверждении начала. Используется `crypto.getRandomValues`, равномерный выбор с rejection sampling.
- Для каждой Major отдельный равномерный бит: 50% upright / 50% reversed. Нет весов, зависимостей или квот на фактический состав расклада.
- Major хранит отдельно два demo-artwork состояния. Reversed выбирает свой файл и дополнительно поворачивает только artwork на 180°. Номер, подписи и controls не поворачиваются.
- Minor имеет единственный `image`, без orientation/reversed-полей. Для него не бросается монета.
- Draws и orientation рекурсивно заморожены. Прогресс обновляется отдельно; восстановление не вызывает RNG. Нет индивидуального reroll.
- Нажатие фиксирует открытие один раз. Flip — 820 мс, без эффектов; reduced motion — 0 мс. Даже прерванный навигацией flip не создаёт новую карту.
- Будущую позицию нельзя выбрать/открыть. После раскрытия нужна отдельная команда продолжить; следующая карта не открывается автоматически. Открытые позиции можно пересматривать.
- После последней карты сначала завершается ритуал, затем пользователь отдельно открывает placeholder толкования. Значения, keywords и прогнозы отсутствуют в demo data.

Сессия хранится только в `sessionStorage` этой вкладки, под отдельным prototype-ключом. В ней: схема, вопрос, drawn identities, Major orientations/art states, число открытых карт, активная позиция и completion. Сохраняется при внутренней навигации, посещении A/C и перезагрузке. Хранилища Kadat не читаются и не изменяются. Если sessionStorage недоступен, работает память страницы с явным сообщением; reload в таком режиме не восстанавливает сессию.

«Начать заново» / выбор другой схемы при существующей сессии требует подтверждения. Отмена сохраняет всё. Подтверждение удаляет текущий расклад; новый набор формируется после следующего подтверждения начала. Истории вопросов, сервера и отправки текста нет.

## Mobile / overview

На 360–430 px показана одна крупная карта, а не сетка из 10/24 artworks. Схема открывается в модальном окне: номера позиций, текущая отметка и открытые позиции. Touch targets не меньше 44 px. Закрытые будущие позиции заблокированы; открытые и следующая доступны для просмотра. Сам переход через схему не раскрывает карту.

На desktop схема остаётся слева от большой активной карты, вопрос и короткая инструкция — справа. У 24-card схемы те же 24 номера; количество artworks на основной странице не растёт. У диалога ограниченная высота и внутренняя прокрутка. Внешнего horizontal overflow нет.

Visual Direction V1 сохранён: near-black, negative space, serif/курсив, кость, редкое состаренное золото, тонкий manuscript-разделитель. Старые `prototype.css`, `concept-d.css`, рубашка D и все исходные SVG/шрифт сохранены побайтно. Лицензия локального шрифта: `assets/fonts/LICENSE.txt`.
