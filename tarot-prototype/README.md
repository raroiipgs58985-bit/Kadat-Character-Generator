# Imperial Tarot — Stage I

Активное сравнение A / C / D для выбора визуального языка. D — дополнительный гибрид A + C; Stage II не начат. Прототип полностью изолирован от четырёх генераторов Kadat: никаких их скриптов, стилей, каталогов или сохранений он не использует.

## Открыть

На обычном сервере Kadat (`npm start`): `/tarot-prototype/`.

- Сравнение: `index.html`
- A: `index.html?concept=a`
- C: `index.html?concept=c`
- D: `index.html?concept=d`

Никакая сборка не требуется. Страница также работает при непосредственном открытии локального `index.html` вместе с соседними файлами. GitHub Pages может обслуживать папку без изменений конфигурации.

## Что можно проверить

- Home, закрытая колода, открытая карта и reversed-пример.
- Ритуал на три карты: открытие только I → II → III.
- Непрерывное переключение A / B / C и экранов.
- Физический flip продолжительностью 820 мс; при `prefers-reduced-motion` — мгновенный переход.
- При reversed artwork повёрнут на 180°, а HTML-подпись остаётся читаемой.
- До завершения показываются только artwork, номер, имя и положение. Смысловые данные не подключены; итоговый экран демонстрирует место будущего толкования.
- Короткий переход из Kadat можно пропустить. Внутри Таро заставка повторно не запускается.
- Вход в будущий архив и окно «О Таро». Полного архива нет.

Три SVG-гравюры и четыре рубашки выполнены специально как demo placeholders. Это не работы John Blanche и не финальные назначения колоды. Production dataset из 78 карт не импортируется. Три названия демонстрационных карт взяты из проекта: The Pilgrim, The Prophet, The Astronomican.

## Проверка

```sh
node tarot-prototype/tests/prototype.test.cjs
npm test
```

Первый сценарий проверяет изоляцию, запрещённое раннее открытие карт, подписи, reversed-пример, сброс и итоговый экран. Второй — существующие проверки Kadat. Подробности браузерной проверки: `VALIDATION.md`.

Удаление одной папки `tarot-prototype/` полностью удаляет прототип. Корневой UI и навигация четырёх генераторов не менялись.
